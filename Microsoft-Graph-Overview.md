# Microsoft Graph Overview

## Overview
Microsoft Graph is Microsoft's unified API platform that provides access to Microsoft 365 services.

## Services Accessible Through Graph
- Entra ID
- Outlook
- SharePoint
- Teams
- OneDrive

## Common Security Assessment Areas
- Application Permissions
- Delegated Permissions
- OAuth Consent
- Conditional Access
- Identity Governance

# Azure Storage Reconnaissance
## Identifying Storage Accounts
Storage accounts often appear as:

<storageaccount>.blob.core.windows.net

Examples may be discovered in:

- Public websites
- JavaScript files
- Configuration files
- Documentation

## Reconnaissance Objectives
When assessing cloud environments:

- Identify storage accounts
- Determine exposure levels
- Review publicly accessible resources
- Validate storage security configurations

## Common Cloud Storage Indicators
Azure:

blob.core.windows.net

AWS:

s3.amazonaws.com

Azure Cloud Apps:

cloudapp.azure.com

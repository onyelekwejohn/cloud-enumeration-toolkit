# Entra ID Guest Enumeration
# Overview
Organizations sometimes invite external users as guests into Microsoft Teams and Microsoft Entra ID.
In certain scenarios, guest accounts may have visibility into users, groups, or organizational structures depending on tenant configuration.

# Key Concepts
- Guest Accounts
- Group Membership
- Teams Access
- Role Assignments
- Identity Exposure

# Security Risks
Misconfigured permissions may expose:
- User information
- Group structures
- Department names
- Organizational relationships

## Recommendations
- Review guest permissions regularly
- Apply least privilege principles
- Monitor external user activity
- Restrict unnecessary directory visibility

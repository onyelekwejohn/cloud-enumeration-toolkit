# Cloud Enumeration Toolkit

A curated collection of tools, references, and notes for cloud reconnaissance, Microsoft 365 enumeration, username discovery, and authentication testing during authorized penetration testing engagements.

## Microsoft 365 Username Enumeration

### 1. o365creeper
Python-based tool used to validate Office 365 usernames through ActiveSync and other enumeration techniques.

Repository:
https://github.com/LMGsec/o365creeper

Use Cases:
- Username validation
- Office 365 reconnaissance
- Email enumeration

---

### 2. Oh365UserFinder
Tool for identifying valid Office 365 accounts and usernames.

Repository:
https://github.com/dievus/Oh365UserFinder

Use Cases:
- O365 user discovery
- Authentication reconnaissance
- Cloud assessment preparation

---

## Notes

These tools are intended strictly for authorized security testing, research, and educational purposes.

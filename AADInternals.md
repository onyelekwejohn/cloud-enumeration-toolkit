# AADInternals

# Overview
AADInternals is a PowerShell framework used for researching and assessing Microsoft Entra ID environments.
Repository:
https://github.com/Gerenios/AADInternals

# Common Use Cases
- Tenant information gathering
- Domain enumeration
- Identity research
- Security assessments
- Cloud security testing

# Examples of Information That Can Be Identified
- Tenant ID
- Tenant domains
- Authentication configuration
- Public identity information

# Notes
AADInternals should only be used in environments where authorization has been granted.

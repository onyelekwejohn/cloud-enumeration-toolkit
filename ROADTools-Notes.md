# ROADTools Notes
Repository:

https://github.com/dirkjanm/ROADtools

## Description
ROADTools is a framework for interacting with Microsoft Entra ID.

Developed by:

Dirk-Jan Mollema

Language:

Python

## Components
### roadlib
Core library.
### roadtx
Authentication and token utilities.
### roadrecon
Directory reconnaissance and analysis.

## Common Use Cases
- Entra ID visibility analysis
- Tenant mapping
- Microsoft Graph interaction
- Identity security assessments

## Learning Goal

Understand how Azure identities, groups, roles, and permissions are structured and exposed through Microsoft Graph.
